# Golf Oly Pay

ゴルフ・オリンピックのポイント入力、対象ホール抽選、最終精算を行うWebアプリです。

## GitHub Pagesで公開する

1. GitHubで新しいPublic repositoryを作成します。
2. このフォルダ内のファイルをすべてリポジトリの最上位へアップロードします。
3. Repositoryの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` で `GitHub Actions` を選びます。
5. `Actions` タブでデプロイ完了を待ちます。
6. `Settings` → `Pages` に公開URLが表示されます。

公開URLの形式:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## iPhoneへの追加

Safariで公開URLを開き、共有ボタン → 「ホーム画面に追加」を選択します。

## データ保存について

入力内容は各端末のブラウザ内に保存されます。複数端末間では同期されません。
